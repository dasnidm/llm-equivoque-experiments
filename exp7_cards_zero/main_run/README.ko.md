# 실험 7 본 실험 실행 설정

- 7개 모델 × 추론 3수준 × obj/seq × 200시행 = 8,400시행.
- 1차는 조합당 첫 100시행, 총 4,200시행이다. 모든 1차 시행이 완료 또는
  프로세스 종료 실패로 정리되고 원본 백업이 확인된 후 2차를 자동 시작한다.
  2차도 조합당 100시행이다. 보류·미확인은 완료나 실패로 추정하지 않는다.
- 하나의 CLI 프로세스와 세션에서 10라운드 및 후속 4턴을 연속 진행한다.
  429 등 확인된 재시도 가능한 턴 오류는 동일한 살아 있는 프로세스에서 실패 턴을
  되돌리고 이력을 대조한 후 큐 뒤에서 재전송한다. 과정과 원본 RPC를 보존한다.
  프로세스가 종료되면 해당 시행을 실패로 보존하고 같은 시행을 재시작하지 않는다.
- 동시 시행 42개, 인위적 전송 간격이나 재시도 횟수 상한 없음. 빈 슬롯은
  같은 차수의 다음 시행으로 채운다. 보류된 라이브 프로세스는 슬롯을 유지한다.
- 34턴이 모두 끝나면 기록·프로세스·세션·재시도를 감사하고 원본을 아카이브한다.
  비공개 저장소의 새 브랜치에 보낸 뒤 별도 캐시로 원격 바이트를 다시 읽어
  SHA256을 확인한다. 그 후에만 해당 종료 시행의 로컬 native scratch를 정리한다.
  인증 파일과 CLI SQLite 데이터베이스는 기존 원본 백업 계약처럼 업로드하지 않는다.
  진행 중·불확실한 시행은 정리하지 않는다.
- [현황판](https://github.com/dasnidm/llm-equivoque-experiments/tree/exp7/cards-0to100-main-100x2-20261118)은
  약 30초마다 갱신되며 모델·추론 수준별 obj/seq의 각 차수 완료 수를 보여준다.
  원본은 비공개 `dasnidm/llm-equivoque-exp7-raw`의 별도 브랜치에 저장한다.
- GitHub 제어 확인, 디스크 여유 5GiB 미만, 비공개 백업 실패 또는 현황판이
  오랫동안 갱신되지 않으면 새 턴 전송을 대기한다. 이미 보낸 요청을 실패로
  추측해 재전송하거나 세션을 중단하지 않는다. 프로세스/컨트롤러가 비정상 종료된
  실행은 미확정 기록을 확인하기 전 자동 재개하지 않는다.

`assignments.jsonl.gz`는 결정적 배정이며 SHA256은
`a98f26b601254c7bf8af4b60c41cd170bc5125d63e62165b519e5fa98bf7fc82`다.
이전 기술 점검, 1–100 시행과 실험 5는 본 표본에 포함하지 않는다.
