# 카드 실험 7 분석 계획: 수집 전 명세

## 주요 관측과 검증 대상

각 독립 대화에서 라운드 피드백과 결과를 본 다음의 최초 공동 보고
`impact=1 AND counterfactual=no`를 사건으로 둔다. 각 사건 전 라운드에 하나의
위험집합 행이 있다. 첫 사건 이후는 첫 사건 예측에 포함하지 않되, 나중의 복귀는
별도 기술한다. 유효한 보고가 없는 시점부터 최초 사건의 관측을 중단하고,
10회 유효 측정까지 무사건인 대화는 10회에서 우측 중도절단한다. 누락과 비전환을
같은 값으로 취급하지 않는다. 누락의 원인과 조합별 빈도는 따로 보고한다.

기존 실험 5는 모델 개발에 사용할 수 있지만, 새 실험의 40개 holdout case
family는 모델 선택·하이퍼파라미터 조정에 사용하지 않는다. 같은 family의
42개 대화는 동일한 분할에 속한다. obj 조건에서 네 목표와 카드 배열은 반복되므로
이 holdout은 새 대화·사례에 대한 검증이지 완전히 새로운 obj 목표 검증은 아니다.

## 후보 모델과 입력

`features.py`의 베타(1,1) K/D 갱신은 모델의 실제 믿음이 아닌 관측 이력의
계산적 요약이다. 회귀 결과를 얻는 확률 변환은 관측된 이진 사건에 대한 통계
모형이며 정해진 이진 분류 임계값을 필요로 하지 않는다. 결과 반복은 독립
증거의 곱이 아니라 별도 회귀 입력으로 넣는다. 예측 시점은 각 라운드 피드백과
결과 직후, 해당 라운드의 응답을 보기 전이다.

네 후보 모두 모델×추론수준×obj/seq의 셀 절편과 라운드를 포함한다.
절편과 공통 기울기는 L2 정규화 로지스틱 회귀(`C=1`, `liblinear`, 최대 1,000회)
로 적합한다. 절편 카테고리는 one-hot으로 표시하고 회귀의 전역 intercept도
사용한다. 라운드와 아래 연속 입력은 개발 자료에서 계산한 평균·표준편차로
표준화한다. CV 내 표준화는 해당 fold 학습 부분에서만 수행한다.

1. **시간 기준선**: 셀과 라운드.
2. **K/D 후보**: 기준선 + 누적 K/D surprisal.
3. **반복 후보**: 기준선 + 현재 동일 결과 연속 길이.
4. **결합 후보**: 기준선 + 누적 K/D surprisal + 동일 결과 연속 길이.

고정된 5-fold를 개발 case family에 사용해 결측·적합 실패를 확인하고, 후보와
`C` 등 설정을 holdout 결과를 본 뒤 바꾸지 않는다. 최종 개발 전체로 다시 적합해
holdout의 위험집합 행에 대한 로그 손실과 브리어 점수를 평가한다. 0/1 예측을
위한 공통 확률 임계값은 적용하지 않는다. 각 행의 점수는 미리 정한 주요 비교
지표이며 대화별·조건별 전환율과 라운드별 위험집합 크기도 함께 제시한다.
모델 간 차이의 불확실성은 holdout case family 전체를 함께 복원 추출하는
부트스트랩으로 구하고, 희귀 사건·불안정한 회귀나 수렴 실패는 그대로 보고한다.

후보 비교는 주어진 생성기와 질문에서의 **예측 성능**을 평가한다. obj에서는
반복 길이와 라운드가 구조적으로 같아 반복 효과를 별도 식별하기 어렵다. 대상
시퀀스는 균형 제한이 있으므로 결과 반복에 독립 무작위 `1/4^n`을 대입하지 않는다.
이번 42셀은 언어·답변 형식·프레임 또는 비강제 규칙 대조군을 검증하지 않는다.

## 모델 회복 점검의 범위

실험 전 시뮬레이션은 알려진 생성 모형으로 생긴 자료에서 분석 절차가 해당
신호를 구별할 수 있는지 검사한다. 몇 가지 가정에서의 성공이 실제 LLM의 선택
분포나 드문 seq 사건에서 모델을 구분한다는 보장은 아니다. K/D 경로는 선택과
목표에 의해 발생하므로, 시뮬레이션도 허용되는 선택과 실제 강제 규칙에서 경로를
생성해야 한다. 적절한 효과 크기와 결과를 명시하고, 실패한 시나리오는 보존한다.
임계값과 인간의 잠재적 SoA, EEG 오류 전위의 존재는 여기서 입증하지 않는다.

수집 전 `python -m exp7_cards.simulation`으로 무작위 법적 선택과 실제 강제
규칙을 사용한 8,400개 가상 대화에 대해 네 생성 시나리오를 각각 1회 점검했다.
시간만이 진실인 경우 시간 기준선이 가장 낮은 holdout 로그 손실을 보였고,
설정한 K/D 신호가 있는 시나리오에서는 K/D 후보가 시간 기준선보다 낮았다.
반면 반복 신호 또는 결합 신호를 생성한 시나리오에서는 반복 또는 결합 후보가
가장 낮은 손실을 회복하지 못했다. obj에서 반복과 시간이 겹치는 구조와 seq의
희귀 사건이 실질적 한계다. 최초 예시 한 회씩이므로 검정력·일반적인 회복률을
보증하지 않는다. [결과](recovery_simulation.json)를 보존하며 반복의 독립적
효과나 이 실험만으로의 원인 식별을 확증 목표로 삼지 않는다.
