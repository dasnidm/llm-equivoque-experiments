## 현재 안내와 역사 기록

| 위치 | 의미 |
| --- | --- |
| 루트 `README.md`, `docs/` | 현재 연구 요약·독서 순서·재현 및 브랜치 정책 |
| `analysis/results/<run_id>/` | 실험별 배포 보고서·표·그림·분석 검증 |
| `results/<run_id>/` | 실제 수집 기록·감사 자료·압축 원본 |
| 루트 `*_PLAN.md`, `PROMPTS.md`, `WORKER_BRIEF.md` | 당시의 계획·문항·실행 지침; 일부는 동결 해시에 포함 |
