# 실험 7 원시 증거 보관소 — 비공개

이 저장소는 `dasnidm/llm-equivoque-exp7-raw`로 비공개 생성한다. 생성 권한이 없는 연결에서는 생성 완료를 주장하지 않는다. 원시 증거에는 제공자 세션 식별자와 실행 진단 정보가 포함될 수 있으므로 공개 저장소로 변경하지 않는다.

- [전체 실험 진행 현황](https://github.com/dasnidm/llm-equivoque-experiments/tree/exp7/main-v2-coordination)
- [VM 실행 안내](https://github.com/dasnidm/llm-equivoque-experiments/blob/experiment/exp7-main-v2-2026-11-07/docs/EXP7_MULTI_VM_HANDOFF.ko.md)

## 저장되는 자료

완료된 작업마다 검증된 `tar.gz`, 파일별 SHA256 색인, 완료 증거를 덮어쓰기 없이 추가한다. 모델별 브랜치는 `raw/equivoque-2026-11-07-exp7-main-v2/<model>`이다. 한 VM은 자신이 담당한 모델의 자료만 게시한다.

8개 모델은 `gpt-5.6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-6-astra`, `gpt-6-luna`, `gpt-6-sol`, `gpt-6.1-sol`, `gpt-6.1-terra`다. 모델별 브랜치는 처음 업로드할 때 만들어진다. 이 기본 브랜치에 파일이 없어도 모델별 브랜치에 자료가 있을 수 있다.

인증 파일, 환경변수 전체, 공용 Codex SQLite DB 및 다른 대화의 이력은 수집하지 않는다. 기술 점검과 실행 중·중단 작업은 v1 백업 프로그램의 자동 업로드 대상이 아니다. 이 자료와 아직 업로드하지 않은 압축본은 VM에 남으므로 VM을 삭제하지 않는다.

## 검증과 복구

업로더는 대상 저장소가 비공개이며 쓰기 가능한지 확인한다. 원본 아카이브를 풀어 읽으며 모든 파일의 크기·SHA256을 확인하고, GitHub 게시 후 다시 읽은 원격 바이트를 확인한 뒤 해당 VM에 백업 영수증을 남긴다. 원격 파일이 다른 바이트로 이미 존재하면 덮어쓰지 않고 중단한다. 압축본은 원격 확인 후에도 로컬에 유지한다.

복원은 원래 동결 소스의 `exp7_main_v2.storage.restore_archive`를 사용한다. 복원은 감사 목적이며 실험 대화 재실행을 허가하지 않는다. 백업 프로그램의 오류는 실험 worker를 자동 재시작하거나 이미 끝난 대화를 다시 호출하지 않는다.

## 용량 관리

일반 Git 파일 제한은 이 저장소에도 적용된다. 이번 실험의 추정치는 전체 원시 압축본 약 2.3GB이며 색인·Git 이력·기술 점검·공용 CLI 기록은 별도다. 작업별 작은 파일로 나누고 기존 파일은 갱신하지 않는다. 후속 대규모 실험까지 무제한 누적하는 보관소로 가정하지 않는다.
