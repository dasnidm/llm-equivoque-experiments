# 실험 7 현황판 — 카드, 0~100

**상태: 준비 중 — 본 수집은 아직 시작하지 않았습니다.**

- 전체: 7개 모델 × 3개 추론 수준 × obj/seq × 200개 = 8,400개 대화
- 1단계: 42개 조합 각각 100개, 총 4,200개
- 2단계: 1단계 전체가 종료 상태로 정리된 후 각 조합의 나머지 100개
- 한 대화: 한 CLI 프로세스와 세션에서 10라운드 및 후속 질문, 총 34턴
- 429: 프로세스와 세션이 유지되고 실패가 확인된 경우에 같은 턴 재시도
- 현재 완료: **0 / 8,400개**

원본 대화는 이 공개 현황판에 게시하지 않습니다. 수집이 시작되면 진행 상황을 자동 갱신합니다.
