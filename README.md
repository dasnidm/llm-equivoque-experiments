# Exp7 v2 frozen execution bundle

Download only **exp7-main-v2-source.tar.gz** and **SHA256SUMS**. Verify the checksum, extract, and follow `exp7_main_v2/README.md`. Full historical repository checkout is unnecessary.

[Worker instructions](https://github.com/dasnidm/llm-equivoque-experiments/blob/experiment/exp7-main-v2-2026-11-07/exp7_main_v2/README.md)

[Live coordination board](https://github.com/dasnidm/llm-equivoque-experiments/tree/exp7/main-v2-coordination)

The bundle contains frozen source and assignments; no credentials or native runtime logs. Model calls require local Codex authentication and successful separate calibration. Each VM claims one free model. Private raw archives remain on each VM; public research exports are uploaded separately.

Release asset uploads were rejected by their authentication endpoint, so this small distribution branch is the supported download channel.
