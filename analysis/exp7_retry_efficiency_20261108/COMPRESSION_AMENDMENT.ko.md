# 실모델 요청 전 로컬 오류와 별도 v2 기술점검

v1의 첫 입장 요청은 `UnicodeDecodeError`로 로컬에서 종료됐다.
CLI가 보낸 압축/비텍스트 요청을 계측용 JSON으로 바로 해석하려 한 코드의 문제다.
물리 admission 기록, HTTP 시도 기록, underlying HTTP 호출은 모두 **0회**다.
따라서 생성된 모델 응답이나 공급자 처리 여부가 불명확한 요청은 없다.

v1의 12개 상태, 원본 RPC, 실패·중단, STOP/HALT, manifest와 실행 로그를
그대로 남겼다. 비공개 원격 백업 commit은
`9426aa424cb034d963bde630e626f05163154c4c`이다.
이 실패 실행을 성공 실행으로 덮어쓰거나 본실험 시행으로 대체하지 않는다.

사용자가 요청한 구현 수정과 효율 검증을 위해 **새 v2 기술점검**을 만든다.

- 실행 범위: `equivoque-2026-11-08-exp7-retry-efficiency-v2`.
- 저장 위치: `/workspace/work/exp7-retry-efficiency-20261108-v2`.
- v1의 모든 STOP을 유지하고 v2는 새 manifest·상태·프로필·대화를 사용한다.
- 요청 본문은 해석·압축 해제·재압축하지 않고 원래 바이트 그대로 전달한다.
  요청 해시와 크기, 허용된 압축 방식 이름만 기록한다.
- 실제 CLI의 34턴·2회 거절 복구 테스트 외에, gzip 본문이 429 뒤에도
  같은 바이트와 `Content-Encoding`으로 전달되는 오프라인 검증을 추가한다.
- 비교 조건·12대화×34턴·순서·재시도 예산·선택 기준은 원래 계획을 유지한다.
  과학 프로토콜이나 기존 freeze는 수정하지 않는다.

v2는 local-only 실패 원인을 고친 별도 운영 검증이다. 실패·불확실 본실험
시행을 임의로 재시도하는 예외로 해석하지 않는다.
