# 실험 7 전체를 API 크레딧으로 실행할 때의 비용

2026-11-08 공식 Standard API 단가와 보존된 실제 토큰 사용량으로 계산했다.
**현재 입력 구성을 유지하고 관측된 캐시 적중률을 재현한다면 약 $14,200~$16,900**이다.
실험 5의 세 추론 수준 자료로 교차 계산하면 약 **$14,900~$17,700**이다.
따라서 예산 규모는 우선 **약 $14,000~$18,000**로 보는 것이 타당하다.
이는 조건부 시나리오이며 통계적 신뢰구간이나 실제 API 청구서가 아니다.

전체 계획은 77,856개 독립 대화 × 34턴 = **2,647,104턴**이다.
모델 8개에 각각 9,732대화/330,888턴을 배정한 manifest를 그대로 사용했다.
새 모델 호출과 API 결제는 하지 않았고, 배정·freeze·STOP도 변경하지 않았다.

## 모델별 규모

단가는 100만 토큰당 USD다. 입력에는 해당 턴에서 다시 처리하는 대화 이력이
포함된다. 아래 비용은 각 모델에 배정된 전체 330,888턴의 추정이다.

Astra와 5.6 Sol은 최근 상한 없는 비교의 각 40대화를 사용했다. 다른 여섯 모델은
앞선 8모델 기술점검의 모델당 한 대화를 사용했다. 모두 medium·영어 schema·cards·seq다.
이를 다른 언어·형식·게임·추론 수준까지 외삽했으므로 특히 여섯 모델의 견적은 잠정적이다.

실험 5 교차 계산에는 **7모델 × 3effort × 120대화 = 2,520대화·83,160턴**을
사용했다. 각 모델의 평균 턴 사용량을 새 330,888턴으로 환산했다. 실험 5에 없던
6.1 Terra만 위의 현재 medium 표본을 유지했다. 교차 계산 $14,856~$17,741은
실행 방식과 질문 구성이 다른 참고값이며 현재 모든 조건을 검증한 값이 아니다.

## 캐시와 비용 불확실성

현재 표본의 캐시 읽기 비율은 모델별 약 54~76%다. 캐시 적중률을 유지하는
조건에서 범위의 아래쪽은 CLI가 기록한 캐시 저장 토큰 0을 그대로 가격에
대입한 값이다. 위쪽은 캐시 읽기를 제외한 입력 전부에 기본 30분 저장 요금
1.25배를 적용한 민감도 계산이다. 직접 API에서 실제로 얼마나 저장 과금될지는
현재 CLI 기록만으로 확정할 수 없다. 이 둘은 모든 불확실성을 포괄하는 한계값이 아니다.

| 캐시 가정: 현재 표본의 입력·출력량 유지 | 전체 비용 |
| --- | ---: |
| 관측 캐시 읽기 비율, 저장 프리미엄 없음 | $14,229 |
| 관측 캐시 읽기 비율, 나머지 입력 전부 30분 저장 과금 | $16,869 |
| 캐시 적중 0, 저장도 하지 않음 | $37,161 |
| 캐시 적중 0, 입력 전부 30분 저장 과금 | $46,132 |

공식 [캐시 문서](https://developers.openai.com/api/docs/guides/prompt-caching)에 따르면
30분 저장은 일반 입력의 1.25배, 12시간 저장은 2.5배이며 이들은 총 저장 단가다.
여기서는 12시간 저장 옵션을 적용하지 않았다.

계산식은 다음과 같다. 추론 토큰은 이미 출력 토큰에 포함되어 있으므로 더하지 않는다.

```text
일반 입력 = 총 입력 - 캐시 읽기 - 캐시 저장
비용 = (일반 입력 × 입력 단가
      + 캐시 읽기 × 캐시 읽기 단가
      + 캐시 저장 × 저장 단가
      + 추론을 포함한 출력 × 출력 단가) / 1,000,000
```

CLI의 각 턴 `usage`는 대화 누적값이다. 이것을 턴마다 더하면 비용을 크게
부풀리므로 **완료 대화의 마지막 누적값만 한 번** 사용했다. 현재 자료에서는
턴별 `usage_last` 합계와 마지막 누적값의 일치도 검증했다.

현재 구성의 전체 외삽 사용량은 입력 약 **133.0억 토큰**, 출력 약 **1.07억 토큰**이다.
$14,229 기준으로 일반 입력 $10,560, 캐시 읽기 $2,393, 출력 $1,276이다.
최종 답변이 짧아도 반복되는 지침·도구 설명·대화 이력의 입력 비용이 크다.

## API 크레딧으로 얼마나 가능한가

8모델의 현재 배정 비율을 유지하고, 위의 관측 캐시/저장 프리미엄 0 가정으로
단순 환산하면 다음과 같다. 실제로 실행 가능한 완전한 배정 단위를 보장하는 값은 아니다.

| 크레딧 | 전체 예산의 비율 | 34턴 대화 환산 |
| --- | ---: | ---: |
| $100 | 0.70% | 약 547대화 |
| $200 | 1.41% | 약 1,094대화 |
| $500 | 3.51% | 약 2,736대화 |

캐시 저장 민감도까지 고려하면 $200은 약 923~1,094대화 규모다.
전체는 77,856대화이므로 구독의 월 크레딧만으로 이번 전체 표본을 감당하기 어렵다.
[적격 구독의 크레딧 혜택](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)은
직접 API 사용과 Codex의 API 키 사용을 구별한다. 해당 계정의 자격이나 잔액은
확인하지 않았으며, 현재 계산이 크레딧 활성화나 결제를 뜻하지 않는다.

## 적용 범위와 재현

- Standard·짧은 컨텍스트 단가이며 Fast/Ultrafast, 지역 할증, 세금, 환율,
  가격 변경, 기술점검·실패·추가 수집 비용은 포함하지 않았다.
- 직접 Responses로 전환하면서 CLI가 추가하는 입력을 정리하면 비용이 달라질
  수 있다. 같은 prompt/effort 표기만으로 입력이나 응답 분포가 같다고 보장하지 않는다.
- 출력이 긴 자연어·한국어 조건, high effort, 캐시 동작 변화는 실제 API 소표본으로
  검증해야 한다. 실험 5 교차 계산으로 이러한 불확실성이 해소되지는 않는다.
- 더 저렴한 모델만 선택하거나 호출·라운드를 줄이는 것은 연구 설계 변경이다.
  이번 계산에서는 그러한 변경을 하지 않았다.
